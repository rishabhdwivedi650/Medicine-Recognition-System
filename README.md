# Medicine Recognition System

A simple Generative AI based web application that analyzes uploaded medicine-related images.

## Features

- Upload a medicine-related image
- Analyze the image using Generative AI
- Display AI-generated information
- Simple web interface

## Technologies Used

- Python
- Flask
- Google Gemini API
- HTML
- Pillow
